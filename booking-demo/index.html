Avyaya — Privacy-Preserving Booking Verification (Demo)

A real, deployed version of the flow scoped in "Avyaya - Privacy-Preserving Booking Verification.docx" — real signed tokens, real server-side checks. The one simulated piece: actual government/third-party ID verification is stood in for by a one-click "demo verify," per the doc's Phase 1 roadmap.

This is a prototype for internal review — not production. The signing key lives in code, not a managed secret, and no real license data is collected anywhere in this demo.
